# ADC 患者端小程序（UC-10）

对应课程报告第 6.12 节的患者端：只有两屏——**自助预约**与**我的预约·取消**，外加一个必填的**实名建档**页（报告 UC-10 扩展 3a）。

原生小程序（WXML/WXSS/JS），没有引框架。两端共用同一套 REST 接口，业务规则一条都不在小程序里重写。

```
adc-miniapp/
├─ app.js / app.json / app.wxss     登录态、tabBar、全局样式
├─ config.js                         BASE_URL 与前后端共享的常量
├─ utils/api.js                      接口封装（带票、401 自动重登）
├─ utils/format.js                   日期与金额展示
└─ pages/
   ├─ book/   自助预约：诊所 → 治疗需求 → 日期 → 时段/牙医 → 确认
   ├─ mine/   我的预约：待就诊 / 历史，24 小时内外分别给“取消”与“致电诊所”
   └─ bind/   实名建档：姓名、性别、出生日期、手机号
```

## 怎么跑起来

1. 先启动后端（默认 `http://127.0.0.1:8080`）：

   ```bash
   java -jar apps/adc-api/target/adc-api-0.1.0.jar --server.port=8080
   ```

2. 打开**微信开发者工具** → 导入项目 → 目录选 `D:\ADC\apps\adc-miniapp`。
   `project.config.json` 里的 `appid` 现在是 `touristappid`（游客模式），自己有小程序 appid 就换掉。

3. 开发者工具 → 详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
   否则 `http://127.0.0.1` 会被拦。

4. 真机预览时，`config.js` 的 `BASE_URL` 改成电脑的局域网地址（如 `http://192.168.1.8:8080`），手机与电脑同一 Wi-Fi。

## 登录与鉴权（报告 6.12）

```
wx.login()  →  code  →  POST /api/wx/login  →  服务端调 jscode2session 换 openid
                                            →  签一张 HMAC 票返回
后续请求    →  Authorization: Bearer <票>  →  拦截器验票 → openid 放进请求属性
                                            →  控制器用 openid 换患者，接口里没有 patientId
```

关键点：**接口不接收患者编号**。改一个数字就想看别人预约，在结构上就做不到；服务端还会再判一次归属，越权返回 403。

`adc.wx.app-id` / `app-secret` 没配时后端走开发模式，openid 由 code 派生，方便在开发者工具里把链路跑通。上线前必须配齐。
生产环境还要把 `adc.wx.token-secret` 换成随机长串。

## 页面上的几条规则来自报告，不是随手加的

| 行为 | 出处 |
| --- | --- |
| 只能看/取消本人预约 | UC-10 约束、6.12 鉴权约束 |
| 取消必须早于 24 小时，否则提示致电诊所 | UC-10 扩展 7a |
| 90 天内两次未到诊，暂停自助预约 | UC-10 扩展 7b |
| 未建档时先填四项实名信息，过敏史留给前台 | UC-10 扩展 3a |
| 有未结清结算单时仍可预约，但把提示带进预约 | UC-10 扩展 3b |
| 时段被别人抢走时刷新列表并提示重选 | UC-10 扩展 2a |
| 单价只读，不提供在线支付 | UC-04 口径、6.12 |

## 本地版式预览（没装开发者工具时）

```bash
node tools/wxml-preview/render.js
```

会读**真实的** wxml/wxss，生成 `docs/miniapp-preview.html`，用浏览器打开即可看三屏版式。
它不实现事件与生命周期，只用来核对排版；交互仍需在开发者工具或真机验证。

## 已知边界

- 员工端已有账号登录与角色权限（`V7__staff_accounts.sql` 种子账号），员工接口按角色放行；
  小程序用到的诊所、治疗项目、可约时段属于**参考数据**，服务端显式放行，不需要员工票。
- 小程序没有接微信「手机号快速验证」，目前手机号靠用户手填；生产环境建议换成 `getPhoneNumber`，服务端解出手机号后再建档，避免用户填别人的号。
